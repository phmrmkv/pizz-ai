# Projeto Pizzaria

Site de venda de pizzas (projeto de estudo): cardápio, detalhe com tamanho e quantidade, carrinho lateral com desconto de 10% e aviso de demonstração ao finalizar. Nada é cobrado.

Feito com Astro, React (ilhas), Tailwind CSS 4 e shadcn/ui (Dialog, Sheet, Sonner).

- `npm run dev`, `npm run check`, `npm run build`, `npm run preview`
- Catálogo em `src/data/catalogo.ts` (preços em centavos); fotos em `src/assets/pizzas/`
- Versão original em HTML + CSS + JavaScript: `referencias/original/` (fora do build)
